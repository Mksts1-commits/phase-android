Connect Phase to your AI agent

No directory listing yet — these paths work today, free.

Option A — Paste the prompt (easiest, works now)

Paste this to any AI agent. It opens the Phase agent guide, which scripts the whole mint flow: one intake form, the full agreement, a typed signature, and standard defaults.

mint my coin -->>is.gd/mintmycoin

Your agent signs you up and holds your Phase access token from there. No setup, no keys to copy.

Option B — Custom connector via MCP (for agent apps that accept an MCP server URL)

Point your agent app at the Phase MCP server:

https://phase-backend.onrender.com/mcp

Seven confirm-first tools: coin setup, agreement, sign, mint, dashboard, marketplace, watchlist. Tools that need your account take your Phase access token as the accessToken argument — it is issued when you sign up or log in, and your agent passes it per call. Trading is not a tool: agents never buy, sell, or swap for you; trading stays manual in the web app.

Note: this is a custom (unreviewed) connection, not the directory listing. The directory submission is prepared and will be filed when the submission site is reachable from here.

Option C — Directory listing (coming)

Phase's directory connector is built (OAuth 2.0 + PKCE live) and its submission is drafted and approved. It will appear in the directory once filed and reviewed. Until then, use Option A or B.
